# Axe Données — Les Archives

**Mentor : Lin — The Keeper**

| Mission | Titre | Notions principales |
|---|---|---|
| 1 | Inventorier les artefacts | tableaux, `push`, `pop`, `splice`, `find`, méthodes de string |
| 2 | Classer les fiches d’artefacts | objets littéraux, déstructuration, spread `...`, JSON |
| 3 | Archiver les chroniques du Nexus | `Date`, classes, instances, tableaux d’objets |
| 4 | Déchiffrer le registre des artefacts | texte vers tableau d’objets, `split`, `filter`, `map`, `reduce`, `sort`, regroupement dans un objet |
| 5 | Ranger la salle des coffres | classe avec getters, fonctions qui modifient un objet reçu, `splice`, `try`/`catch` |
| 6 | Restaurer les chroniques | JSON et `Date`, recréer des instances, déstructuration avec valeurs par défaut, fusion sans doublon |

Les exercices restent courts et centrés sur la manipulation et la structuration des données.

Les missions 4 à 6 sont plus exigeantes : elles importent des fonctions écrites dans les missions précédentes, qui doivent donc être terminées.
